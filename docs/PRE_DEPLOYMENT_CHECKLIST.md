# Pre-Deployment Manual QA Checklist

- [ ] Review key pages at 1440, 1024, 768, 390, and 320px.
- [ ] Tab through every page; verify visible focus and logical order.
- [ ] Test at 200% zoom with no clipped essential content.
- [ ] Spot-check landmarks, headings, links, images, and tables with VoiceOver/NVDA.
- [ ] Measure rendered color contrast.
- [ ] Confirm wide tables scroll cleanly.
- [ ] Confirm Relative stacks cleanly on mobile.
- [ ] Open every PDF download and external link.
- [ ] Run Lighthouse/accessibility diagnostics; fix substantive issues, not score-chase.
- [ ] After deployment, verify GitHub Pages paths and canonical/preview metadata.
- [ ] Ask 2–3 research hiring reviewers: “After five minutes, what kind of researcher does this portfolio make me look like?”
