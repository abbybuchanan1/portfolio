# Abby Buchanan Portfolio

Static portfolio implementation governed by Portfolio Design & Implementation Specification v1.0.

## Run locally
Serve the repository root with any static server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Architecture
- `index.html` — homepage
- `work/scaffold.html` — primary UX research case study
- `work/scaffold/` — native HTML research artifacts
- `research/` — research initiative and memos
- `observation/` — secondary observation practice
- `about.html` — background and approach
- `resume.html` — resume page
- `assets/` — CSS, images, and source PDFs
